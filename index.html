표 도구

    

  







  

    
붙여넣고 정리

    

      

        브라우저가 클립보드 자동 읽기를 허용하지 않았습니다.

        아래 칸에 붙여넣기(Ctrl+V / Cmd+V) 하면 바로 정리합니다.
      

      
    

    

      
      
    

  







  

    
바꾸기

    

      

        
        
        
      

      
      

        현재 메모 전체에 즉시 적용되고, 되돌리기 한 번으로 복구됩니다.
        저장된 자동 바꾸기 규칙은 "정리" 실행 시 적용되며 코드블록 안은 건드리지 않습니다.
      

    

    

      
      
    

  







  

    
마법사

    

      
      

      

        규칙으로 해석되는 명령(여백·들여쓰기·글머리·강조·구분선·출처·바꾸기)은 즉시 처리됩니다.
        "더 간결하게 써줘" 같은 자유 편집 명령은 AI 연결(2차 개발 예정)이 필요합니다.
      

    

    

      
      
    

  







  

    
정리 규칙 설정

    

      

        
편집기 등폭 폰트
표의 열을 칼같이 맞춰 봅니다. 켜면 편집 화면 전체가 등폭 글꼴로 바뀝니다

        
      

      

        
굵은 강조 (**텍스트**)
40자가 넘는 문장 전체 강조는 항상 마커만 제거

        
      

      

        
구분선 (---)

        
      

      

        
제목 (#, ##)

        
      

      

        
글머리 기호 (-, *)

        
      

      

        
소제목 여백
위 2줄·아래 1줄, 투명 문자(ㅤ)라 카톡·블로그에서도 유지

        
      

      

        
글머리 들여쓰기

        
      

      

        
출처 링크 제거
ChatGPT·퍼플렉시티가 붙이는 [1]: URL 출처 블록과 본문 [1] 표시 제거

        
      

      

        
대시 나열 목록화
"– a – b – c" 한 줄 나열을 줄 목록으로 분리

        
      

      

        
투명 문자 소제목 정리
ㅤ로 감싼 유사 소제목에 위아래 빈 줄, 제목 규칙 적용

        
      

      

        
AI 마법사 연결 (자유 편집)

        

          Anthropic API 키를 넣으면 "더 간결하게 써줘" 같은 자유 편집 명령을 마법사가 처리합니다.
          키는 이 기기에만 저장되고, 호출 비용은 키 소유자에게 청구됩니다.
        

        

          
          
        

      

      

        
자동 바꾸기 규칙

        

          위에서부터 순서대로 적용. 바꾸기에 \n을 쓰면 줄바꿈. 코드블록 안은 건드리지 않습니다.
        

        

        
      

      

      

        설정은 저장 즉시 반영되며, 이후 "정리"를 실행할 때부터 적용됩니다.
        이미 정리해 둔 메모는 소급해서 바뀌지 않습니다. 원본이 필요하면 되돌리기를 사용하세요.
